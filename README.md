# Command Keywords 插件

通过设置面板配置关键词列表，将这些关键词视为“命令词”。当消息内容**完全等于**某个关键词时，插件会拦截该消息，阻止 AstrBot 的默认 LLM 回复链路。

## 功能
- 关键词命令拦截（避免触发 LLM 默认回复）
- 支持大小写敏感配置
- 支持列表或字符串格式关键词配置

## 配置项

```json
{
  "enable": true,
  "keywords": ["菜单", "帮助"],
  "case_sensitive": false
}
```

- `enable`：是否启用拦截
- `keywords`：关键词命令列表  
  - 可填数组或字符串
  - 字符串支持逗号/空格/分号分隔（例：`菜单,帮助 help`）
- `case_sensitive`：是否区分大小写

## 使用说明
1. 安装并启用插件。
2. 在设置面板中填写关键词列表。
3. 当用户发送的消息 **完全等于** 关键词时：
   - 事件会被拦截
   - 默认 LLM 回复不会触发

## 说明
- 仅拦截 **完全匹配** 的消息文本（不做包含匹配）。
- 该插件只阻止默认 LLM 链路，不影响其他插件自定义处理。
